# 저장한 글의 소유와 저장 흐름

## Decisions

- 저장한 글은 저장 시점의 변환 결과 사본을 보관합니다. 열 때 원본 URL을 다시 가져오지 않습니다.
- 저장한 글은 만든 사용자 본인만 읽고 쓸 수 있습니다. 다른 사용자와 비로그인 사용자에게는 보이지 않습니다.
- 홈 화면의 변환은 로그인 없이 계속 쓸 수 있습니다. 로그인은 저장할 때만 요구합니다.
- 로그인하지 않은 사용자가 저장을 누르면 변환 결과를 보존한 채 로그인 화면으로 보내고, 로그인에 성공하면 보존한 결과를 자동으로 저장합니다.

## Boundaries

- 이 결정은 프롬프트 저장을 허용하지 않습니다. 프롬프트는 [url-to-markdown](url-to-markdown.md) 결정대로 저장하지 않습니다.
- 로그인 화면 왕복 중 보존한 결과가 사라진 경우(탭을 닫았거나 다른 기기에서 가입을 마친 경우)는 저장 없이 로그인만 끝나도 정상입니다.

## Why

저장 시점의 사본을 두는 이유는 사용자가 저장한 순간의 글을 나중에도 같은 모습으로 보기 위해서입니다. 원본 페이지는 바뀌거나 사라질 수 있고, 다시 가져오면 변환 실패 가능성도 생깁니다.

비로그인 변환을 막지 않는 이유는 기존 홈 화면의 사용 방식을 유지하기 위해서입니다. 저장을 누른 사람이 변환을 다시 해야 하는 불편은, 사용자가 '결과를 보존한 채 로그인 후 자동 저장'을 직접 골라 없앴습니다.

## Still-rejected alternatives

- 저장 버튼을 누르면 로그인 화면으로만 보내고 결과는 버리는 방식 — 가장 단순하지만 사용자가 같은 URL을 다시 변환해야 합니다. 사용자가 채택하지 않았습니다.
- 비로그인 사용자에게 저장 버튼을 숨기는 방식 — 이동은 없지만 저장 기능을 발견하기 어렵습니다.
