# URL → Markdown 변환 후 LLM으로 넘기기

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여 주고, 복사·다운로드하거나 ChatGPT·Claude에 바로 넘길 수 있는 서비스입니다.

## 사용자에게 보이는 결과

1. URL을 입력하고 변환하면 페이지 제목·저자 헤더와 렌더링된 Markdown 본문이 보입니다.
2. 결과를 복사하거나 `.md` 파일로 내려받을 수 있습니다.
3. 프롬프트(프리셋 또는 직접 입력)를 선택적으로 앞에 붙여 ChatGPT 또는 Claude로 넘길 수 있습니다.
4. 라이트/다크 모드를 토글로 바꿀 수 있습니다.

## 승인된 범위

- **입력**: URL 입력창, 지우기 버튼(입력과 결과를 모두 초기 상태로 되돌림).
- **변환**: 본문 추출과 Markdown 변환에 `defuddle` 라이브러리를 반드시 사용합니다.
- **결과 확인**: 제목과 저자를 담은 헤더, 그 아래 렌더링된 Markdown.
- **내보내기**: 복사하기, `.md` 다운로드, ChatGPT로 열기, Claude로 열기.
- **프롬프트**: 프리셋 `요약해줘` / `한국어로 번역해줘` / `쉽게 설명해줘`, 그리고 `직접 입력`. 프롬프트 없음도 선택할 수 있습니다.
- **다크모드 토글**.

## 수용 기준

1. 공개된 기사형 페이지 URL(예: `https://en.wikipedia.org/wiki/Markdown`, `https://defuddle.md/docs`)을 변환하면 제목, 저자, 비어 있지 않은 Markdown 본문이 표시됩니다.
2. 지우기 버튼을 누르면 입력창과 결과가 모두 비워집니다.
3. 잘못된 URL(형식 오류, `http`/`https`가 아님)은 변환을 시도하지 않고 오류 메시지를 보여 줍니다. 페이지를 가져오지 못했거나 본문을 추출하지 못한 경우에도 이해할 수 있는 오류 메시지를 보여 주며, 이전 결과는 남지 않습니다.
4. 변환 중에는 로딩 상태가 보이고, 그동안 중복 요청이 나가지 않습니다.
5. 저자 정보가 없는 페이지는 저자 없이 제목만 헤더에 표시됩니다.
6. **복사하기**는 현재 선택된 프롬프트(있다면)와 Markdown 본문을 합쳐 클립보드에 넣고, 복사됐다는 피드백을 보여 줍니다. 프롬프트가 없으면 본문만 복사합니다.
7. **.md 다운로드**는 Markdown 본문만 담은 파일을 내려받습니다. 프롬프트는 포함하지 않으며, 파일명은 페이지 제목에서 만듭니다.
8. **ChatGPT로 열기 / Claude로 열기**는 `[프롬프트 + Markdown 본문]`을 클립보드에 복사하고, 해당 서비스의 새 채팅을 새 탭으로 엽니다. 본문 길이와 관계없이 동작하며, 복사됐으니 입력창에 붙여넣으면 된다는 안내를 보여 줍니다.
9. 프리셋을 고르면 해당 문구가, 프롬프트 없음을 고르면 아무것도 앞에 붙지 않습니다. `직접 입력`을 고르면 텍스트 입력창이 나타나고, 다른 선택으로 바꾸면 사라집니다. 직접 입력한 문구는 새로고침이나 지우기 후에 남지 않습니다(저장하지 않음).
10. 다크모드 토글로 전체 화면의 테마가 바뀌고, 새로고침 후에도 마지막 선택이 유지됩니다. 선택한 적이 없으면 OS 설정을 따릅니다.
11. 좁은 화면에서도 입력, 결과, 내보내기 동작이 모두 사용 가능합니다.

## 확정된 제약과 이유

- **긴 본문은 URL에 싣지 않고 클립보드로 넘깁니다.** ChatGPT·Claude의 `?q=` 방식은 URL 길이 한계 때문에 긴 문서(위키피디아 문서가 약 3만 4천 자)를 담지 못합니다. 사용자가 이 방식으로 확정했습니다(붙여넣기 한 번이 더 필요한 대신 항상 동작).
- **defuddle은 필수**입니다(사용자 요구). 서버에서 `linkedom` 또는 `jsdom`과 함께 쓰는 구성이 위 두 URL에서 모두 제목·저자·본문 추출에 성공함을 스크래치에서 확인했습니다(2026-11-18, defuddle 0.19.6).
- 외부 페이지는 브라우저에서 직접 가져올 수 없는 경우가 많으므로(CORS), 페이지를 가져오는 일은 브라우저 바깥에서 이루어져야 합니다.
- 프롬프트는 저장하지 않습니다(사용자 요구).
- UI는 `docs/decisions/ui-composition.md`를 따릅니다(shadcn 구성, semantic token, 공통 shell, 상태 설계).
- **비주얼 방향은 사용자가 준 참고 이미지 기준으로 확정했습니다.** 어두운 배경, 초록 포인트 색, 위쪽 스포트라이트, 제목 아래 원형 장식, 가운데 정렬 제목, 돋보기 아이콘이 있는 큰 입력 바입니다. 라이트·다크 모두 같은 초록 포인트를 씁니다.
- 초록 포인트는 현재 흑백인 `app/globals.css`의 `--primary`(와 `--ring`)를 바꾸는 방식으로 적용합니다. 화면마다 임의 색을 덮어쓰지 않고 semantic token으로 표현하는 원칙은 그대로 유지합니다. 구체 값은 `prototype.html`의 `visual direction` 블록을 따릅니다.

## 가정 (덮어쓸 수 있음)

- UI 문구는 한국어입니다.
- 프롬프트 기본값은 "없음"이며, 프리셋 문구는 버튼 라벨과 같은 문장을 그대로 씁니다.
- 프롬프트와 본문 사이는 빈 줄 하나로 구분합니다.
- 변환은 URL 하나에 대한 1회성 요청이며 이력은 남기지 않습니다.
- 다크모드 선택은 브라우저에 저장합니다.
- 로그인이 필요한 페이지, JS로만 그려지는 페이지는 지원하지 않으며 오류로 처리됩니다.
- 승인된 프로토타입(`prototype.html`)은 화면 구성의 기준입니다. 내보내기 버튼은 본문 카드 아래, 프롬프트 선택과 같은 패널에 둡니다(긴 문서에서는 스크롤이 필요하며, 결과 카드 상단으로 올리는 안은 채택하지 않았습니다).
- 참고 이미지의 `⌘ K` 단축키 표시는 이 서비스에 맞지 않아 넣지 않았습니다.
- 프로토타입에서 768px 너비는 따로 검토하지 않았습니다. 구현에서는 390px과 데스크톱 사이에서 레이아웃이 깨지지 않으면 충분합니다.

## 범위 밖 (이유)

- 보안 하드닝(내부망 주소 차단, 요청 제한 등), 성능 방어, 스펙에 없는 엣지케이스: 강의용 학습 템플릿의 검증 예산 방침입니다.
- 변환 이력, 계정, 프롬프트 저장, 여러 URL 일괄 변환, 이미지 처리 옵션.
- ChatGPT·Claude 외 다른 LLM 서비스.

## 보류 사항

없음.

## 남은 위험

- ChatGPT·Claude의 새 채팅 주소와 동작은 외부 서비스가 바꿀 수 있습니다. 로그인 필요 여부는 사용자 계정 상태에 따라 달라지며 이 스펙이 보장하지 않습니다.
- 일부 사이트는 서버 측 요청을 차단하거나 본문을 JS로만 그려, 추출이 실패하거나 품질이 낮을 수 있습니다.
- 클립보드 쓰기는 브라우저 권한 정책의 영향을 받습니다. 실패하면 사용자에게 알려야 합니다.
